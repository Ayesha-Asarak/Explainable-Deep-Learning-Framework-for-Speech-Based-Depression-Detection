🔬 Methodology

  • Participant-only speech + acoustic features
  • Random Forest (deployed) + occlusion XAI
  • CNN + Grad-CAM kept as baseline only
  • Official AVEC train/dev/test evaluation

📊 Dataset

  • DAIC-WOZ style interview recordings
  • 5 depressed · 4 non-depressed participants
  • Binary classification task
  • Clinical assessment labels

🧠 Model

  • 3-layer CNN on mel spectrograms
  • Acoustic feature MLP for SHAP
  • Segment aggregation at inference
  • Participant-level training split
